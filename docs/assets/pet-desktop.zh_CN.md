# Mac 桌面补给站 0.2.1

标题区收紧，版本移至页脚。主按钮在「开始送饭」和「暂停送饭」之间切换，检测数据源时为「停止检测」；USB 操作仍不可取消。锁定期间连接设置保持可读，顶部只说明运行状态，不冒充胸牌已联网。黄色饭盒区突出待吃食物，送达时间明确为快照。菜单栏原有启停命令不变。

面向 Apple Silicon、macOS 12.3+ 的内测 App，包含原生中文窗口、菜单栏和 Python 3.12 运行环境。使用者不用另装 Python、Git、ESP-IDF，也不用终端操作 App。仍需本人有权使用的 Kaboo CLI，支持兼容的 `export --format csv`；首次安装和配对需要 USB 数据线，日常需要蓝牙。本包不支持 Intel 和 Windows；第二台干净 Mac、原厂胸牌安装仍待验收。

## 第一次使用

1. 核对分发者提供的 ZIP SHA-256。解压，把 `AI Pet Passport.app` 移到 `/Applications` 或自己的 `~/Applications`，再打开。内测包只有 ad-hoc 完整性签名，**不是 Developer ID 签名，也没有 Apple 公证**。确认来源后按系统提示处理，不要关闭 Gatekeeper；公司受管电脑可能需要 IT 批准。
2. 停止旧版送饭脚本，只接一台胸牌。尚未安装本宠物固件时点击「安装固件」，先备份和检查，再由本人确认写入。原有其他应用会被替换；它不是通用原厂刷机器，详见[安装安全说明](pet-mac-install.zh_CN.md)。
3. 启动后在胸牌打开宠物并领养蛋，点击「USB 配对」。老用户选择「使用旧版配对」或「载入配对…」。密钥遗失不会偷偷重置，不同胸牌不能共用密钥。
4. App 自动寻找常见 Kaboo 安装位置（包括 nvm）；没找到就选择自己的 CLI 可执行文件。正常使用产生今日数据后，点击「检测」，再「开始送饭」，按 macOS 提示授权蓝牙。
5. 只有胸牌返回认证确认才显示送达。最近送达、待吃食物、阶段、陪伴天数都是快照，不是实时监控。仍在**胸牌上按确定**吃饭，电脑不会凭空加餐或加成长。

## 平时怎么用

- 每轮尝试结束后约一分钟再读取本机累计用量。数据源失败、没有今日数据、蓝牙断开会重试，不发送伪造的零；相同快照不会重复给食物。
- 主窗口「暂停送饭」或菜单栏「停止送饭」会结束本轮读取、搜索或同步，不删除成长。关窗口后菜单栏继续运行；从菜单栏显示、开始、停止、退出。退出会等待同步线程结束；USB 检查或刷写期间禁止退出。
- 登录自启**默认关闭**。用户勾选并确认后才创建本人账户的登录项，且 App 必须已移入 Applications。取消勾选会移除该项。不安装系统服务、自动更新器、云服务或提权助手。
- 登录项用隔离文件测试，未注销本机做真实登录测试。睡眠唤醒、新账户权限、企业策略由后续安装测试确认。

## 只用 Kaboo，不接官方月结

本期只用 Kaboo 喂养，不运行官方月结连接器，也不承诺官方结算。保留本地跨月和家族图鉴；新的待对账归档改显示「本地成长记录」，不再让用户等待不存在的服务。v5 存档及高级可选对账协议保留兼容，不删除旧记录。

## 隐私、故障和恢复

偏好与最近确认摘要存于 `~/Library/Application Support/AI Pet Passport/`，目录 700、文件 600。配对密钥和整机备份仅留本机。通过原有应用层加密协议，把汇总快照发给本人已配对胸牌；原始 CSV 只在内存处理，临时扫描缓存每轮清理。导出限制 64 MiB、120 秒。停止时只终止本轮创建的导出进程组，不影响已有 Kaboo 程序。

不要分享密钥、备份、原始导出或整个私有文件夹。反馈只需 App 版本、macOS/芯片、界面错误和失败步骤。分发包不带个人配置、内部导出器或官方月结连接器。Kaboo 自身的数据与网络行为不由本 App 改写。角色素材为同人内容，代码许可证不授予角色再分发权。

分区、Recovery、身份检查失败时，在写应用前停止。保留备份联系维护者，不要擦机或换不安全工具绕过。本维护者当前胸牌 Recovery 早已为空，无法用它证明原厂安装正向链路；现有宠物固件仍能日常喂养。即使恢复区有有效镜像头，也不代表已经实测启动成功。

## 维护者构建和验收

在 Apple Silicon 上使用可分发的独立 CPython 3.12，不要打包 Apple Command Line Tools Python。隔离环境安装 `tools/requirements-pet-desktop-build.txt`，记录 Python 源压缩包 SHA-256，再运行：

```bash
python tools/build_pet_desktop.py --firmware /path/to/FoloToy-AI-Passport-full.bin --version VERIFIED_COMMIT --output /new/build-directory
python tests/test_pet_desktop.py
python tests/test_pet_wireless.py
./tools/validate.sh --static
```

构建工具验证固件，嵌入运行依赖及许可证，生成饭盒图标和蓝牙用途说明，校验 ad-hoc 签名并执行冻结包冒烟检查。固件必须来自对应 CI 验证的产物；不覆盖已有构建目录。

检查 ZIP 解压和换目录、最小 PATH 下启动、数据源发现、原有私钥复用、真实蓝牙认证送达、停止与重试、关窗口、菜单栏重开和退出。解压后重新验证签名与冒烟测试。安装正反例沿用安全安装器，不对预检失败胸牌刷写。正式 Developer ID 签名和公证需所有者 Apple 账户/证书另行完成，ad-hoc 校验不能当成公开发行许可。
