# Mac 内测安装

这是中文终端向导，不是已签名／公证的应用，也不是离线免依赖安装器。需要 macOS 12.3+、Python 3.9–3.13（推荐 3.12）、USB 数据线及首次下载 Python 依赖的网络。直接获得 ZIP 的用户不需要 Git、ESP-IDF、Codex 或 GitHub 账号。另一台干净 Mac 与 Windows 尚未验收。

## 用户流程

先把 ZIP SHA-256 与可信发布者提供的值核对，解压并保留整个目录，双击 `.command` 启动器。如被 macOS 拦截，请验证来源后按系统安全提示操作，不要关闭 Gatekeeper。缺 Python 时先从 python.org 安装 3.12；启动器不会安装 Xcode 或 Homebrew。安装固定顶层版本的 Python 依赖到私有虚拟环境前会请求确认。

1. 停止旧送饭进程，只接一台 Passport，选 1。
2. 输入 `CHECK`，检查／重启并备份设备。备份与兼容性检查通过后输入 `INSTALL` 才刷写，其他输入取消写入。
3. 等胸牌启动，重新打开向导选 3，输入 `PAIR`。检查家族 v5／存储健康，通过 USB 创建私有配对密钥并核验确认。胸牌上打开宠物应用，选择主线领蛋。
4. 选 4，选择已配对胸牌，填写本人有权使用的 Kaboo CLI 路径，或回车从 PATH 查找 `kaboo-cli`。导出器需支持 `export --format csv` 及本项目要求的列。正常使用后有今天的数据才通过预检。
5. 系统提示时授权蓝牙，保持窗口运行，约每分钟同步。只有胸牌认证 ACK 才表示投食成功。Ctrl-C 停止，不安装自启服务；休眠或蓝牙失联延后同步，不惩罚宠物。

向导防止自身多个实例并发，但不能停止或识别所有旧送饭脚本，请手动关闭旧脚本。独立配对档案按原生 USB 序列号的哈希区分，不按可复用的串口名区分。已配对胸牌缺少本机密钥时拒绝，不重置。高级参数 `--config` 可显式选择原有私有密钥文件，不能复用其他胸牌的密钥或发给别人。

## 安全与恢复

只接受安装器核对的精确五分区布局，其他原厂／应用布局拒绝；这不是通用出厂烧录器。不兼容设备需走厂商兼容安装流程，本宠物固件的小程序安装链路仍未实测。

要求 ESP32-C3、8 MB Flash、未启用安全启动／Flash 加密、分区字节与 MD5 匹配、已知 UP Recovery 钩子、非空身份区和 Recovery ESP 镜像头。这些检查不能证明 Recovery 能实际启动。允许写入前完整读取 8 MiB 两次并比较，整个过程保留同一串口连接，断线不会自动重连重试写入。只刷 `0x10000` 应用，不写 bootloader、分区表、NVS、身份和 Recovery。原来的其他应用会被替换，不保证任意第三方存档兼容。

重启前再次读取全 Flash，验证应用字节及 3 MB 应用槽外两段保护区。这与之后的启动／配对检查、真实蓝牙／Kaboo 投食分别验收。失败即停止，不提供自动全盘恢复、降级或擦除命令。保留备份，先让维护者确认失败阶段与同一实物设备，再讨论恢复。

私有备份、每台设备的配对密钥、运行环境在 `~/Library/Application Support/AI Pet Passport/`，使用私有权限。不要把此目录、原始导出或敏感终端输出发给维护者。ZIP 白名单不包含用户备份、设备身份、配对密钥、内部 Kaboo 实现和官方月结连接器，不会自动开启官方月结。标准导出器使用隔离临时扫描缓存；维护者私有的缓存加速导出器未随包分发。安装器不上传数据，Kaboo 本身的行为仍由其自身决定。

SHA-256 能检测损坏，不能防止 ZIP 和清单一起被恶意替换，请从可信来源获取。角色素材是同人内容，代码许可证不代表角色或商业分发授权。

## 维护者打包

使用对应 CI 已验证的 merged 固件和固定版本 esptool 环境，拒绝覆盖已有 ZIP：

```bash
python3 tools/package_pet_mac.py --firmware /path/to/FoloToy-AI-Passport-full.bin --version c8bcd65-pilot1 --output /path/to/AI-Pet-Passport-Mac.zip
```

包中保留 Recovery 所需的 merged 产物，但 USB 向导仅提取并验证应用，绝不直接刷 merged 文件。清单记录两个摘要与应用大小；ZIP 包含逐文件摘要、中文快速说明和双语手册。打包不等于发布，不自动创建 tag、GitHub Release 或社区上架。本次安装器没有改变固件，不需要为了验证主机逻辑而重编译／刷写同一固件。
