数码宝贝 Passport · Mac 内测包

这不是已签名／公证的 Mac App，也不是免依赖安装包。
需 macOS 12.3+、Python 3.9–3.13（推荐从 python.org 安装 3.12）、联网、USB 数据线。
解压后保留整个目录。先核对发布者给出的 ZIP SHA-256，再双击「开始使用.command」。
如系统拦截，请核验来源，并按 macOS 系统设置中的安全提示处理；不要关闭系统保护。

第一次：
1. 停止旧的送饭脚本，只连接一台 Passport。选择 1 安装固件。
2. 阅读提示，输入 CHECK；备份完成且全部检查通过后，输入 INSTALL 才会刷写。
3. 等胸牌启动，再打开向导，选择 3。检查通过后输入 PAIR，独立配对。
4. 选择 4，填写你有权使用的 Kaboo CLI 路径（或回车自动寻找）。
5. 正常使用 Kaboo 后等待导出包含今天数据；只有收到胸牌认证 ACK 才算送饭成功。
6. 在胸牌「数码宝贝」里选一条主线，领取自己的数码蛋。

之后：选择 4 运行期间约每分钟同步。关闭窗口、电脑休眠会暂停，不会饿死。
没有后台自启。没有默认接入官方月结，没有内置内部 Kaboo 加速导出器。
请勿同时运行多个旧版同步脚本。蓝牙权限需用户在系统提示中授权。

安全边界：
仅支持已验证的五分区布局。分区不符、缺少身份／恢复区域、安全启动或加密设备会被拒绝。
仅更新应用区，不全盘擦除。原机其他应用会被替换，不保证其存档能被宠物程序读取。
校验摘要只能检测损坏，不能代替发布者身份验证。
私有备份与密钥在 ~/Library/Application Support/AI Pet Passport/，不要发给他人或提交 GitHub。
旧设备已有配对但本机没有密钥时停止，不强行换绑。请找回原机私有配置后由维护者指导。
失败请记录失败阶段；不要发整机备份、配对文件、原始用量或敏感终端日志。
请勿自行全盘回刷备份或降级固件，先联系维护者确认同一设备和恢复范围。

当前是小范围内测；另一台干净 Mac、Windows、双机互通和长期续航仍需独立验收。
