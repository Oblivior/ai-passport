AI Pet Passport · 伙伴补给站 0.2.1

仅 Apple Silicon Mac（M 系列芯片），macOS 12.3+。
内嵌 Python，不需要 Git、Codex、ESP-IDF 或终端操作。
仍需你自己有权使用的 Kaboo CLI，支持 export --format csv。

1. 核对分发者的 ZIP SHA-256，解压，把 App 拖到 Applications 后打开。
2. 停止旧版送饭脚本，只连接一台 Passport。
3. 新设备：安装固件 → 等待启动并领养宠物 → USB 配对。
   已有宠物：不要重刷，使用旧版配对或载入原有 link.json。
4. 选择 Kaboo 程序，正常使用产生今日数据后点「检测」。
5. 点「开始送饭」，按 macOS 提示允许蓝牙；同一按钮可暂停送饭。
6. 食物送达后，在胸牌上按确定喂宠物。

关窗口不会停止，菜单栏可重新打开或退出。登录自启默认关闭。
只使用 Kaboo 日常数据，不需要官方月结。跨月仍会留存家族图鉴。

重要边界：
- 本包只有 ad-hoc 完整性签名，尚无 Developer ID 签名/Apple 公证。
  确认来源后按系统安全提示操作，不要关闭 Gatekeeper；受管 Mac 可能需 IT 批准。
- 安装会替换旧应用，只写应用区；先备份、再校验、再确认。
- 分区/身份/Recovery 不兼容会停止，不要绕过检查或全盘擦除。
- 原厂正向安装、第二台干净 Mac、双胸牌相遇仍需独立验收。
- 不要发送配对密钥、备份、原始用量或私有配置给任何人。
- 数码宝贝为同人角色，代码许可不代表角色商业/再分发授权。
